Fins ara hem treballat amb pàgines web creades només amb **HTML i CSS**. Aquestes pàgines són **estàtiques**: mostren informació, però no poden recordar res del que escriu l'usuari. Per construir aplicacions reals (com un formulari d'inscripció que desi les dades de l'alumnat), necessitem introduir un **servidor web**, un llenguatge de servidor (**PHP**) i una **base de dades (MySQL)**.

<PresentacioIntroBbdd />

### Resum conceptual abans de començar

| Concepte | Què és? | Per a què el farem servir al projecte? |
| :--- | :--- | :--- |
| **Servidor web (Apache)** | El programa que rep les peticions del navegador i serveix les pàgines. | Permetrà obrir el nostre projecte des de `http://localhost/...`. |
| **PHP** | Llenguatge de programació que s'executa al servidor (ocult a l'usuari). | Rebrà les dades del formulari (`$_POST`) i les enviarà a la base de dades. |
| **Base de dades (MySQL)** | Sistema d'emmagatzematge organitzat en taules (files i columnes). | Guardarà de forma permanent cada alumne inscrit a la taula `materies`. |

---

## Pas 1: Instal·lar i arrencar XAMPP

**XAMPP** és un paquet gratuït que instal·la al nostre ordinador un servidor web (**Apache**), el motor de **PHP** i el sistema de bases de dades **MySQL / MariaDB**.

1. Descarrega i instal·la **XAMPP** des de la seva web oficial (`apachefriends.org`) mantenint les opcions per defecte (`Apache`, `MySQL`, `PHP` i `phpMyAdmin`).
2. Obre el programa **XAMPP Control Panel**.
3. Prem el botó **Start** a la fila de **Apache** i el botó **Start** a la fila de **MySQL**.
4. Comprova que tots dos noms es posen de **color verd** (això indica que el servidor local està encès i escoltant peticions).

:::tip[On s'han de desar tots els fitxers del projecte?]
Apache només pot executar fitxers PHP que estiguin guardats dins la carpeta pública del servidor:
* **Windows:** `C:\xampp\htdocs\`
* **macOS:** `/Applications/XAMPP/htdocs/`

Dins d'aquesta carpeta `htdocs`, crea una carpeta nova per al teu projecte (per exemple, `projecte_materies`). Tot el que posis allà dins es podrà obrir des del navegador escrivint `http://localhost/projecte_materies/...`.
:::

---

## Pas 2: Accedir a phpMyAdmin

Amb Apache i MySQL engegats en verd al panell d'XAMPP:

1. Obre el navegador web (Chrome, Firefox o Edge).
2. A la barra d'adreces, escriu:
   ```text
   http://localhost/phpmyadmin
   ```
   *(També hi pots entrar prement el botó **Admin** de la fila MySQL al panell d'XAMPP).*

## Pas 3: Crear la base de dades i la taula `materies`

Ara crearem l'estructura exacta que esperarà el nostre codi PHP més endavant.

<ConstructorTaulaSql />

Segueix aquests passos dins de **phpMyAdmin**:

1. **Crear la base de dades:**
   * A la columna esquerra, fes clic a **Nova** (*New*).
   * Al camp *Nom de la base de dades*, escriu exactament:
     ```text
     formulari_materia
     ```
   * Prem el botó **Crea** (*Create*).

2. **Crear la taula:**
   * Dins de `formulari_materia`, et demanarà crear una taula nova.
   * Escriu el nom **`materies`** i indica **5 columnes** (o **4 columnes** si no hi poses l'`id`). Prem **Continua** (*Go*).

3. **Configurar els camps (columnes):**
   Omple les files amb aquests noms i tipus exactes:

   | Nom de la columna | Tipus | Longitud / Valors | Extra / Índex |
   | :--- | :--- | :--- | :--- |
   | `id` | `INT` | *(buit)* | Marca la casella **`A_I`** (*Auto Increment*) → S'assignarà com a `PRIMARY` |
   | `nom` | `VARCHAR` | `50` | — |
   | `cognoms` | `VARCHAR` | `100` | — |
   | `mail` | `VARCHAR` | `100` | — |
   | `materia` | `VARCHAR` | `50` | — |

4. Prem el botó **Desa** (*Save*) a la part inferior dreta.

:::caution[Molt important: respecta les minúscules!]
Tant el nom de la base de dades (`formulari_materia`) com el de la taula (`materies`) i el de cada columna (`nom`, `cognoms`, `mail`, `materia`) han d'estar escrits en minúscules i sense accents. Si hi ha una sola lletra diferent, la connexió PHP fallarà.
:::
