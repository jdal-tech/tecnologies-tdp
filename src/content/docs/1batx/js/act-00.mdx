**JavaScript (JS)** és un llenguatge de programació d'alt nivell i interpretat: el navegador llegeix i executa les instruccions línia per línia sense necessitat de compilar-les prèviament. És el llenguatge que converteix una pàgina web estàtica en una aplicació interactiva.

## 2. Com funciona? Client, DOM i Servidor

Tot i que JavaScript va néixer per executar-se dins del navegador de l'usuari (**costat del client**), avui dia és un llenguatge tot terreny que també funciona als servidors (**costat del servidor**).

<Tabs>
  <TabItem label="Costat del Client (El navegador)" icon="laptop">
    Quan obres una pàgina web, el teu navegador (Chrome, Firefox, Safari) utilitza el seu propi motor per executar el codi JavaScript en temps real. A més, connecta amb **APIs** (*Interfícies de Programació d'Aplicacions*):
    * **API del DOM (*Document Object Model*):** Permet que JavaScript llegeixi i modifiqui qualsevol etiqueta HTML o estil CSS de la pantalla al moment.
    * **APIs externes:** Permeten connectar la nostra web amb serveis reals com mapes (**Google Maps**), dades meteorològiques (**OpenWeather**) o reproducció multimèdia (**Spotify**).

<Aside type="caution" title="Java no és JavaScript!">
  Tot i compartir quatre lletres al nom per una decisió comercial de l'any 1995, **Java** i **JavaScript** són dos llenguatges completament diferents. JavaScript és el llenguatge natiu del web, mentre que Java s'utilitza principalment per a aplicacions empresarials o Android.
</Aside>

## 3. Tres regles d'or de la sintaxi de JavaScript

Abans de començar a programar, recorda aquestes tres característiques fonamentals del llenguatge:

| Característica | Què significa? | Exemple correcte | Exemple erroni |
| :--- | :--- | :--- | :--- |
| **Tipat dinàmic i dèbil** | No cal indicar si una variable és un número (`int`), decimal (`float`) o text (`string`); JS ho detecta sol. | `let edat = 16;`<br/>`let nom = "Laia";` | `int edat = 16;` *(error de sintaxi)* |
| **Case-sensitive** | Distingeix estrictament entre majúscules i minúscules. Dues paraules amb una majúscula diferent són variables diferents. | `let puntuacio = 10;`<br/>`console.log(puntuacio);` | `let puntuacio = 10;`<br/>`console.log(Puntuacio);` *(ReferenceError)* |
| **Estil `camelCase`** | Bona pràctica per anomenar variables de diverses paraules: la primera en minúscula i cada paraula següent en majúscula, sense espais ni accents. | `notaMitjanaCurs`<br/>`preuFinalAmbIva` | `nota mitjana curs` *(espais prohibits)*<br/>`notamitjanacurs` *(difícil de llegir)* |

## 4. El nostre entorn de treball: Visual Studio Code

Per desenvolupar les activitats d'aquest mòdul treballarem amb **Visual Studio Code (VS Code)**. Ja disposeu de **Live Server** (per previsualitzar pàgines web en directe) i **Prettier** (per mantenir el codi ben endreçat), però per a JavaScript afegirem una extensió clau:

<Aside type="tip" title="Nova extensió: Quokka.js">
  Permet executar codi JavaScript en temps real dins del mateix editor i veure el resultat de cada operació o `console.log()` al costat de la línia, sense necessitat de crear un fitxer HTML.

  * **Drecera per activar-lo:** `Cmd + K, Q` (Mac) o `Ctrl + K, Q` (Windows) → *New JavaScript File*.
</Aside>

<Aside type="note" title="Consola del navegador (F12)">
  **Quokka.js** és ideal per practicar variables, condicionals, bucles i funcions (ACT 1 a 5). Quan connectem JavaScript amb botons i formularis HTML (ACT 6), utilitzarem **Live Server** juntament amb la pestanya **Console** de les eines de desenvolupador del navegador (`F12`).
</Aside>
