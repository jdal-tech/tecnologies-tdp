#### 1.2 Operadors matemàtics i conversió `Number()` <Badge text="EXER_02" variant="caution" />

1. Declara dues variables numèriques: `base = 8` i `altura = 5`.
2. Calcula l'àrea d'un rectangle (`base * altura`) en una tercera variable i mostra-la per consola.
3. Demana un número a l'usuari amb `prompt()`, converteix-lo a número real amb `Number()` i suma-li `10`. Mostra el resultat per consola.

<SimuladorJS 
  codi={[

    'let area = base * altura;',

    { text: 'Àrea: 40' },
    { text: '[Finestra prompt] Usuari escriu: "15"' },
    { text: 'Resultat + 10: 25' }
  ]}

#### 1.5 Condicional IF / ELSE amb Prompt <Badge text="EXER_05" variant="caution" />

1. Demana a l'usuari una contrasenya utilitzant la funció `prompt()` i guarda la resposta en una variable.
2. Escriu una estructura `if / else` per verificar si la contrasenya introduïda és igual a `"1234"`.
3. Si és correcta mostra un `alert("Accés Concedit")`; si és incorrecta, mostra un `alert("Accés Denegat")` al bloc `else`.

<SimuladorJS 
  codi={[
    'let clauUsuari = prompt("Introdueix la contrasenya:");',
    '',
    'if (clauUsuari === "1234") {',

    '} else {',
    '  alert("Accés Denegat");',
    '}'
  ]}
  sortida={[
    { text: '[Finestra prompt] Usuari escriu: "1234"' },
    { text: '[Finestra alert] Accés Concedit' }

#### 6. Recórrer un Array amb un bucle `for` <Badge text="EXER_06" variant="caution" />

1. Crea un array anomenat `moduls` amb 4 assignatures o tecnologies (ex: `["HTML", "CSS", "JavaScript", "Arduino"]`).
2. Escriu un bucle `for` que recorri l'array des de la posició `0` fins a `moduls.length`.
3. Dins del bucle, mostra cada element per consola precedit del seu número de posició.

<SimuladorJS 
  codi={[
    'const moduls = ["HTML", "CSS", "JavaScript", "Arduino"];',
    '',
    'for (let i = 0; i < moduls.length; i++) {',
    '  console.log("Tema " + (i + 1) + ": " + moduls[i]);',
    '}'
  ]}
  sortida={[
    { text: 'Tema 1: HTML' },
    { text: 'Tema 2: CSS' },
    { text: 'Tema 3: JavaScript' },
    { text: 'Tema 4: Arduino' }
  ]}
/>

#### 7. Creació de Funcions i `return` <Badge text="EXER_07" variant="caution" />

1. Defineix una funció anomenada `calcularIVA` que rebi un paràmetre `preu`.
2. Dins de la funció, calcula el preu amb el 21% d'IVA (`preu * 1.21`) i retorna el resultat amb la paraula clau `return`.
3. Crida la funció dues vegades amb valors diferents (ex: `100` i `50`) i mostra els resultats per consola.

<SimuladorJS 
  codi={[
    'function calcularIVA(preu) {',
    '  let total = preu * 1.21;',
    '  return total;',
    '}',
    '',
    'console.log("Preu 100€ amb IVA:", calcularIVA(100));',
    'console.log("Preu 50€ amb IVA:", calcularIVA(50));'
  ]}
  sortida={[
    { text: 'Preu 100€ amb IVA: 121' },
    { text: 'Preu 50€ amb IVA: 60.5' }
  ]}
/>

<div style="margin-top: 10px; color: #d4d4d8;">

- **Variables:** `let` es pot modificar; `const` és un valor fix.
- **Matemàtiques:** `prompt()` sempre retorna un text; fes servir `Number(valor)` abans de sumar o multiplicar.
- **Concatenar:** Cal afegir els espais manualment amb `" "`. La primera posició d'un array és `0`.
- **Comparadors:** `==` compara valor; `===` compara valor i tipus de dada.
- **Bucles:** `array.length` indica quants elements té la llista en total.
- **Funcions:** `return` envia el resultat fora de la funció perquè el puguis guardar o imprimir.
