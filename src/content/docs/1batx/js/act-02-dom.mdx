#### 2.4 Modificar text de la pàgina amb `.textContent` <Badge text="DOM_04" variant="caution" />

2. Selecciona l'element amb `getElementById("estat")` des de JavaScript.

#### 2.5 Selecció per classe amb `getElementsByClassName` <Badge text="DOM_05" variant="caution" />

1. Crea tres paràgrafs a l'HTML i assigna la mateixa classe a dos d'ells (Ex: `class="destacat"`).
2. Selecciona els elements per la seva classe utilitzant `document.getElementsByClassName("destacat")`.
3. Aplica un fons de color groc a tots els elements seleccionats fent ús d'un bucle `for` per recórrer la col·lecció d'elements.

<SimuladorJS 
  codi={[
    'let elements = document.getElementsByClassName("destacat");',
    '',
    'for (let i = 0; i < elements.length; i++) {',
    '  elements[i].style.backgroundColor = "yellow";',
    '}'
  ]}
  htmlInicial={`<p style="margin:4px 0;">Paràgraf 1 (destacat)</p>
<p style="margin:4px 0;">Paràgraf 2 (normal)</p>
<p style="margin:4px 0;">Paràgraf 3 (destacat)</p>`}
  htmlFinal={`<p style="margin:4px 0; background-color:#fef08a; padding:2px 4px;">Paràgraf 1 (destacat)</p>
<p style="margin:4px 0;">Paràgraf 2 (normal)</p>
<p style="margin:4px 0; background-color:#fef08a; padding:2px 4px;">Paràgraf 3 (destacat)</p>`}
/>

#### 2.7 Escoltar clics amb `addEventListener` <Badge text="DOM_07" variant="caution" />

1. Crea un botó `<button id="btn-tema">Activar Mode Fosc</button>` i una caixa `<div id="caixa">Contingut de prova</div>`.

3. Quan l'usuari hi faci clic, canvia el color de fons de la caixa a fosc (`#1e293b`) i el color de la lletra a blanc (`white`).

#### 2.8 Llegir un `<input>` de text amb `.value` <Badge text="DOM_08" variant="caution" />

1. Crea un camp de text `<input type="text" id="campNom">`, un botó `<button id="btnSaludar">Saludar</button>` i un paràgraf buit `<p id="salutacio"></p>`.
2. Quan es premi el botó, llegeix el text que ha escrit l'usuari dins de l'input fent servir `.value`.
3. Mostra dins del paràgraf `<p id="salutacio">` el missatge `"Hola, [nom]!"` amb `.textContent`.

<SimuladorJS 
  codi={[
    'const input = document.getElementById("campNom");',

    'const sortida = document.getElementById("salutacio");',

    '  sortida.textContent = "Hola, " + input.value + "!";',
    '});'
  ]}
  htmlInicial={`<div>
  <div style="display:flex; gap:6px; margin-bottom:8px;">
    <div style="flex:1; border:1px solid #cbd5e1; padding:4px 8px; border-radius:4px; color:#94a3b8; font-size:0.8rem;">Escriu el teu nom...</div>
    <button style="background:#0082C1; color:white; border:none; padding:4px 10px; border-radius:4px; font-size:0.8rem;">Saludar</button>
  </div>
  <p style="margin:0; font-size:0.85rem; color:#64748b;">(Esperant salutació)</p>
</div>`}
  htmlIntermig={`<div>
  <div style="display:flex; gap:6px; margin-bottom:8px;">

<summary style="color: #ef4444; font-weight: bold; cursor: pointer;">[ + VEURE PISTES DE L'ACTIVITAT ]</summary>

<div style="margin-top: 10px; color: #d4d4d8;">

- **Selecció única:** `getElementById("nom")` no porta `#` davant de l'identificador.
- **Canvi de text vs estil:** `.textContent` modifica el text visible; `.style.propetat` modifica el CSS (recorda usar *camelCase* com `backgroundColor`).
- **Col·leccions:** `getElementsByClassName` i `getElementsByTagName` retornen una llista d'elements, per això necessites un bucle `for` per modificar-los tots.
- **Formularis:** Per llegir el que s'escriu dins d'un `<input>` es fa servir `.value`, mai `.textContent`.

</div>
