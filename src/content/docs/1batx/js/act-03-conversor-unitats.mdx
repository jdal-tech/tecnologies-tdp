#### 3.1 Conversor simple amb `prompt()` i `alert()` <Badge text="CONV_01" variant="caution" />

1. Demana a l'usuari una temperatura en graus Celsius (`ºC`) utilitzant `prompt()` i converteix-la a número amb `Number()`.
2. Calcula l'equivalència en graus Fahrenheit aplicant la fórmula: `(celsius * 9 / 5) + 32`.
3. Mostra el resultat final a l'usuari utilitzant un `alert()` i imprimeix-lo també per consola.

#### 3.2 Conversor múltiple amb interfície HTML <Badge text="CONV_02" variant="caution" />

1. Crea a l'HTML un camp numèric `<input type="number" id="graus">`, un botó `<button id="btnConvertir">Convertir</button>` i un paràgraf `<p id="resultat"></p>`.
2. Quan l'usuari premi el botó (`addEventListener`), llegeix el valor de l'input amb `Number(input.value)`.
3. Calcula simultàniament la conversió a **Kelvin** (`celsius + 273.15`) i a **Fahrenheit** (`(celsius * 9 / 5) + 32`).
4. Mostra totes dues conversions concatenades dins del paràgraf `<p id="resultat">`.

<SimuladorJS 
  codi={[
    'const input = document.getElementById("graus");',
    'const boto = document.getElementById("btnConvertir");',
    'const resultat = document.getElementById("resultat");',
    '',
    'boto.addEventListener("click", function () {',
    '  let celsius = Number(input.value);',
    '  let kelvin = celsius + 273.15;',
    '  let fahrenheit = (celsius * 9 / 5) + 32;',
    '',
    '  resultat.textContent = celsius + " ºC = " + kelvin + " K | " + fahrenheit + " ºF";',
    '});'
  ]}
  htmlInicial={`<div>
  <div style="display:flex; gap:6px; margin-bottom:8px;">
    <div style="flex:1; border:1px solid #cbd5e1; padding:4px 8px; border-radius:4px; color:#94a3b8; font-size:0.8rem;">Graus ºC...</div>
    <button style="background:#0082C1; color:white; border:none; padding:4px 10px; border-radius:4px; font-size:0.8rem;">Convertir</button>
  </div>
  <p style="margin:0; font-size:0.85rem; color:#64748b;">Aquí apareixerà la conversió...</p>
</div>`}
  htmlIntermig={`<div>
  <div style="display:flex; gap:6px; margin-bottom:8px;">
    <div style="flex:1; border:2px solid #0082C1; padding:4px 8px; border-radius:4px; color:#0f172a; font-size:0.8rem; background:#f8fafc; font-weight:bold;">20<span style="color:#0082C1;">|</span></div>
    <button style="background:#006ba1; color:white; border:none; padding:4px 10px; border-radius:4px; font-size:0.8rem; box-shadow:0 0 0 2px #bae6fd;">🖱️ Convertir</button>
  </div>
  <p style="margin:0; font-size:0.85rem; color:#64748b;">Aquí apareixerà la conversió...</p>
</div>`}
  htmlFinal={`<div>
  <div style="display:flex; gap:6px; margin-bottom:8px;">
    <div style="flex:1; border:1px solid #cbd5e1; padding:4px 8px; border-radius:4px; color:#0f172a; font-size:0.8rem;">20</div>

#### 3.3 Validació de camps buits amb `if / else` <Badge text="CONV_03" variant="caution" />

1. Millora el codi de l'exercici anterior per evitar que calculi `0 ºC` si l'usuari prem el botó amb la casella buida.
2. Abans de fer els càlculs, comprova amb un `if (input.value === "")` si el camp està buit.
3. Si està buit, mostra un missatge d'avís en vermell dins de `resultat` (Ex: `"⚠️ Escriu un valor numèric"`). En cas contrari (`else`), executa la conversió normalment.

<SimuladorJS 
  codi={[
    'boto.addEventListener("click", function () {',
    '  if (input.value === "") {',
    '    resultat.textContent = "⚠️ Escriu un valor numèric";',
    '    resultat.style.color = "red";',
    '  } else {',
    '    let celsius = Number(input.value);',
    '    let kelvin = celsius + 273.15;',
    '    resultat.style.color = "black";',
    '    resultat.textContent = celsius + " ºC = " + kelvin + " K";',
    '  }',
    '});'
  ]}
  htmlInicial={`<div>
  <div style="display:flex; gap:6px; margin-bottom:8px;">
    <div style="flex:1; border:1px solid #cbd5e1; padding:4px 8px; border-radius:4px; color:#94a3b8; font-size:0.8rem;">Graus ºC...</div>
    <button style="background:#0082C1; color:white; border:none; padding:4px 10px; border-radius:4px; font-size:0.8rem;">Convertir</button>
  </div>
  <p style="margin:0; font-size:0.85rem; color:#64748b;">Esperant dades...</p>
</div>`}

<div style="margin-top: 10px; color: #d4d4d8;">

- **Conversió numèrica:** Tant `prompt()` com `input.value` retornen text. Embolcalla-ho amb `Number(...)` abans de sumar `273.15` perquè no et concateni els números com a text.
- **Decimals:** Si surten molts decimals (ex: `293.15000000000003`), pots arrodonir el resultat final fent servir `kelvin.toFixed(2)`.
- **Validació:** Comprova `input.value === ""` **abans** de convertir-lo amb `Number()`, perquè `Number("")` retorna `0` i el programa es pensaria que l'usuari ha escrit zero graus.

</div>
